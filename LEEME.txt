HX TONE STUDIO · APINEX · SIN CLOUDFLARE WORKER
================================================

ARCHIVOS
- index.html: aplicación completa, autocontenida; publícala en la raíz de GitHub Pages.
- No se necesita worker.js ni instalar dependencias.

CAMBIOS
- Busca canciones y carátulas en el catálogo de Apple/iTunes.
- Al elegir una canción genera un preset con APInex usando el modelo free/gpt-6-luna.
- Incluye conversación contextual: las preguntas responden en texto y las peticiones aplican cambios visuales a la cadena.
- La cadena muestra Input con parámetros de Noise Gate, numera hasta ocho efectos DSP y termina con Output. Input y Output no cuentan entre los ocho.
- Conserva las rutas Live/PA, snapshots, edición de parámetros, perfiles de guitarra y biblioteca local.
- Los presets y la clave de API se guardan solo en este navegador.

CONFIGURACIÓN
1. Abre la app publicada por HTTPS.
2. Pulsa “Configurar APInex” y pega tu clave API.
3. Usa “Probar conexión” y luego “Guardar clave”.
4. Busca una canción para generar su cadena.

PRIVACIDAD Y LIMITACIONES
- La clave se guarda en localStorage del navegador y se envía directamente a api.apinex.bond. No la pegues en el código ni publiques una captura que la muestre. Si compartes el navegador o el equipo, borra la clave desde la configuración.
- La conexión directa requiere que APInex permita CORS desde el dominio de GitHub Pages. Si el navegador muestra un error CORS, la app no puede evitarlo sin un proxy/backend; en ese caso habrá que volver a usar un Worker o una función de servidor.
- Los límites gratuitos de APInex son administrados por APInex y pueden cambiar.
- La búsqueda y las carátulas requieren internet.
- La cadena es una recomendación visual; la app no crea un archivo .hlx ni escribe al pedal. Revisa nombres y parámetros en HX Edit antes de usarla.
