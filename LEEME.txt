HX TONE STUDIO · V3 · PAQUETE LISTO PARA GITHUB PAGES
======================================================

ARCHIVOS
- index.html: app autocontenida; súbela a la raíz del repositorio de GitHub Pages.
- worker.js: proxy para Apple Search y Gemini en Cloudflare.

NOVEDADES
- Al elegir una canción puedes usar Gemini automático o ChatGPT manual.
- El modo manual genera un prompt específico con canción, guitarra y partes marcadas; cópialo en ChatGPT y pega aquí su respuesta JSON para verla como cadena, parámetros y snapshots.
- “Guardar preset” conserva la recomendación en este navegador. “Mis presets” permite ver Todo, Gemini y ChatGPT con carátula, canción y artista; puedes abrir o borrar.
- Los presets se guardan localmente en este navegador/dispositivo actual; no se sincronizan entre teléfono y computadora.

ACTUALIZAR GITHUB PAGES
1. Extrae el ZIP.
2. En tu repositorio, reemplaza el index.html publicado por el index.html de este paquete.
3. Espera a que Pages publique la actualización y recarga la página.

ACTUALIZAR CLOUDFLARE WORKER (OPCIONAL)
1. Abre el Worker existente y reemplaza su código por worker.js.
2. Conserva los secretos GEMINI_API_KEY y APP_TOKEN y la variable CORS_ORIGIN.
3. Despliega el Worker. No pegues la API key en GitHub ni en la página.
4. En la app, configura la URL workers.dev y el APP_TOKEN, luego usa “Probar conexión”.

El Worker intenta gemini-3.8-flash, gemini-3.7-flash y gemini-3.6-flash; reintenta errores transitorios y da un mensaje claro si la cuota del proyecto está agotada. El modo ChatGPT manual no requiere Worker ni clave Gemini. La búsqueda de canciones y carátulas requiere internet.
